## Context

当前 MD to DOCX 转换器在前端使用 Vue 3 + Monaco Editor，后端使用 FastAPI + python-docx。用户上传 Markdown 文件后，系统会自动立即调用转换接口。对于大型文档（100页），这种自动转换会导致：
1. 用户无法在转换前检查文档内容
2. 自动转换消耗不必要的服务器资源
3. 用户体验不够灵活

## Goals / Non-Goals

**Goals:**
- 实现手动触发转换机制，用户上传 MD 或编辑内容后需手动点击转换按钮
- 转换按钮在内容为空或正在转换时禁用
- 保持现有功能正常：模板上传、导出 DOCX、打印预览

**Non-Goals:**
- 不修改后端转换逻辑
- 不增加新的 API 接口
- 不改变现有数据流

## Decisions

1. **移除自动转换逻辑**
   - 移除文件上传时的自动 `convertMarkdown()` 调用
   - 移除编辑器内容变更时的自动转换（debounce 逻辑）

2. **添加手动转换按钮**
   - 在页面顶部添加"转换"按钮
   - 点击后调用转换 API 并显示预览
   - 按钮状态根据内容是否为空和转换状态进行控制

3. **保留现有功能**
   - 模板上传后不自动应用转换
   - 导出和打印功能保持不变

## Risks / Trade-offs

- **风险**：用户可能不清楚需要点击转换按钮
  - **缓解**：在预览区域添加提示信息，引导用户点击转换按钮

- **风险**：无

- **权衡**：相对于自动转换，手动转换增加一步操作，但提供了更好的用户体验和资源控制
